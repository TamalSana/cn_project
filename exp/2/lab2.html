Experiment 2: VLAN Configuration & Inter-Switch Trunking

Aim

To configure Virtual Local Area Networks (VLANs) across multiple switches (AB1 and AB2) and set up a trunk link between them to allow inter-switch VLAN communication.

VLAN Allocation Scheme

VLAN IDVLAN NameSubnetAccess Interfaces (AB1)Access Interfaces (AB2)
10SCOPE192.168.1.0/24Fa0/1 - Fa0/2Fa0/1 - Fa0/2
20SENSE192.168.1.0/24Fa0/3 - Fa0/4Fa0/3 - Fa0/4
30CTS192.168.2.0/24Fa0/5 - Fa0/6Fa0/5 - Fa0/6

Switch CLI Configuration Snippet

AB1> enable
AB1# configure terminal
AB1(config)# vlan 10
AB1(config-vlan)# name SCOPE
AB1(config-vlan)# exit

AB1(config)# interface range fastEthernet 0/1-2
AB1(config-if-range)# switchport mode access
AB1(config-if-range)# switchport access vlan 10
AB1(config-if-range)# exit

! Configure Trunk Port
AB1(config)# interface gigabitEthernet 0/1
AB1(config-if)# switchport mode trunk

Conclusion

VLANs SCOPE, SENSE, and CTS were successfully created across switches AB1 and AB2. Trunking enabled communication between hosts in the same VLAN across different switches while maintaining broadcast domain isolation.
