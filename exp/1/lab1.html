# Experiment 1 Lab 1: Basic Star Topology Configuration

Computer Networks Laboratory

Experiment 1: Configuration of a Basic Star Topology

Aim

To configure a basic Local Area Network (LAN) using a central switch and test connectivity between host devices in Cisco Packet Tracer.

Hardware / Software Requirements

  • Cisco Packet Tracer (CPT)
  • 1× Cisco Catalyst 2960 Switch (Switch0)
  • 3× End Devices (PC0, PC1, PC2)
  • Copper Straight-Through Cables

Network Addressing Scheme

DeviceIP AddressSubnet MaskConnected Node
PC050.100.100.1255.0.0.0Switch0
PC150.100.100.2255.0.0.0Switch0
PC250.100.100.3255.0.0.0Switch0

Procedure

  1. Place a 2960-24TT Switch (Switch0) in the workspace.
  2. Add three Generic PCs (PC0, PC1, PC2).
  3. Interconnect each PC to Switch0 using Copper Straight-Through cables via respective FastEthernet interfaces.
  4. Configure static IP addresses and subnet masks for each PC via Desktop > IP Configuration.
  5. Verify physical connectivity by checking that link status indicators turn green.

Verification / Test Results

C:\> ping 50.100.100.2
Pinging 50.100.100.2 with 32 bytes of data:
Reply from 50.100.100.2: bytes=32 time<1ms TTL=128
Packets: Sent = 4, Received = 4, Lost = 0 (0% loss)

Conclusion

The Star Topology network was successfully created in Cisco Packet Tracer and communication across devices was verified with zero packet loss.
