Experiment 3: DNS & Web Server Configuration

Aim

To configure a local Domain Name System (DNS) server and a Web Server in Cisco Packet Tracer, map a custom domain name (vitap-cn-lab.ac.in) to the web server's IP address, and successfully access the web page from client PCs.

Network Addressing Scheme

DNS Server0Name Resolution (DNS)10.0.0.1255.0.0.0N/A
Web Server1HTTP Hosting (Web)10.0.0.2255.0.0.010.0.0.1

Server Configuration Steps

  1. DNS Server: Set DNS Service to ON. Add A Record mapping vitap-cn-lab.ac.in to 10.0.0.2.
  2. Web Server: Edit index.html under HTTP service tab to host custom university web content.
  3. Client Configuration: Configure static IP and point DNS Server IP to 10.0.0.1.

Verification

Opening the Web Browser on client PCs and navigating to http://vitap-cn-lab.ac.in successfully loads the hosted HTML page.

Conclusion

The local DNS Server and Web Server were successfully integrated. Client machines successfully resolved domain names and loaded the web pages over HTTP.
